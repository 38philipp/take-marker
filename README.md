# Take-Marker

Bauzeichnung, Platine, Test-Suite und Auswertung für den Take-Marker, ein Gerät auf dem Blitzschuh der Kamera. Projektunterricht 2026/27.

Online: https://38philipp.github.io/take-marker/

- `docs/` ist die Website (GitHub Pages, Branch main, Ordner docs).
- `bin/build.py` baut `docs/` neu aus den Quelldateien.
- Die Test-Suite braucht Chrome oder Edge (Web Serial) und das Gerät per USB.
